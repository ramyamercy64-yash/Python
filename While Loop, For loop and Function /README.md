 Loops and Functions

## Overview

This assignment covers Python while loops, for loops, control statements, and functions through three practical programs.

## Programs Included

### 1. Number Guessing Game

* Generates a random number between 1 and 10.
* Allows the user to make guesses.
* Uses `while`, `continue`, `break`, and `else`.
* Provides feedback for incorrect guesses.

### 2. Multiplication Table Generator

* Accepts a number from the user.
* Uses a `for` loop and `range()` to generate the multiplication table from 1 to 10.

### 3. BMI Calculator

* Defines a function called `calculate_bmi()`.
* Accepts weight and height as inputs.
* Calculates BMI and displays the result to two decimal places.

## Python Concepts Practiced

* While Loop
* For Loop
* If-Elif-Else Statements
* Break and Continue
* Functions and Return Values
* User Input and Type Conversion
* Random Number Generation
* Arithmetic Operations

## Learning Outcome

Practiced loops, control flow, and functions by developing simple interactive Python programs.
