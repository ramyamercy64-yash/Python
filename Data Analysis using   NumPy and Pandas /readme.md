#  Data Analysis using NumPy and Pandas

## 📌 Project Overview
This project focuses on learning Python data analysis techniques using **NumPy and Pandas**. It covers array operations, Series manipulation, and DataFrame analysis through practical exercises.

## 🎯 Objectives
- Understand NumPy arrays and their properties.
- Perform numerical calculations and array slicing.
- Create and manipulate Pandas Series.
- Explore and filter transaction data using Pandas DataFrames.
- Perform grouping, aggregation, and data manipulation operations.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Jupyter Notebook / Google Colab

## 📊 Assignment Tasks

### 1. NumPy Array Operations
- Create 1D and 2D arrays using temperature data.
- Inspect array shape, data type, and number of elements.
- Convert temperatures from Celsius to Fahrenheit.
- Calculate maximum, minimum, and mean temperatures.
- Perform array slicing and indexing.
- Extract weekly and weekend temperatures.

### 2. Pandas Series
- Create a Series containing student marks with custom index labels.
- Retrieve values using `loc` and `iloc`.
- Filter marks greater than 90 using Boolean indexing.
- Update student marks and remove a Series entry.
- Calculate CGPA by dividing marks by 10.

### 3. Pandas DataFrame
- Create a transaction dataset with transaction IDs, product categories, regions, and amounts.
- Explore data using `head()`, `tail()`, `shape`, `columns`, and `dtypes`.
- Filter transactions based on region and amount.
- Find product category counts and unique regions.
- Calculate average transaction amounts by region.
- Update transaction amounts, create a discount column, remove a row, and delete a column.

## 📈 Key Learning Outcomes
- Gained practical experience with NumPy arrays and numerical computations.
- Learned Series indexing, slicing, and Boolean filtering.
- Practiced DataFrame exploration and data manipulation.
- Understood grouping and aggregation for basic data analysis.
