# Python – Data Visualization

## 📌 Project Overview

This project focuses on data cleaning and data visualization using Python. The Seaborn Taxis dataset is used to explore taxi trip information and understand different patterns through visualizations.

The main objective is to analyze taxi fares, trip distances, payment methods, pickup boroughs and other important factors using different visualization techniques.

## 🎯 Objectives

- Load and explore the Taxis dataset.
- Identify and handle missing values.
- Perform data cleaning using Pandas.
- Create visualizations using Matplotlib and Seaborn.
- Understand relationships between numerical and categorical variables.
- Gain practical experience in Python data visualization.

## 🛠️ Tools and Technologies

- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📂 Dataset Description

**Dataset:** Taxis Dataset (Seaborn Built-in Dataset)

The dataset contains information about taxi trips, including:

- Pickup and Dropoff timestamps
- Passengers
- Distance
- Fare
- Tip
- Tolls
- Total Amount
- Payment Method
- Pickup Zone and Borough
- Dropoff Zone and Borough

## 🧹 Data Cleaning

The following data-cleaning steps were performed:

1. Loaded the Taxis dataset using Seaborn.
2. Checked dataset information and dimensions.
3. Identified missing values in different columns.
4. Handled missing numerical and categorical values.
5. Used median for numerical columns where required.
6. Used mode for categorical columns where appropriate.
7. Removed rows with missing critical values such as pickup timestamp and fare.
8. Verified missing values after cleaning.

## 📊 Data Visualizations

### 1. Matplotlib / Pandas Visualizations

- **Line Chart:** Analyzed fare over pickup time.
- **Bar Chart:** Compared total fare by pickup borough.
- **Pie Chart:** Visualized payment method distribution.
- **Histogram:** Analyzed trip distance distribution.
- **Box Plot:** Compared tip amounts across pickup boroughs.

### 2. Seaborn Visualizations

- **Count Plot:** Displayed the number of trips by pickup borough.
- **Scatter Plot:** Analyzed the relationship between distance and fare.
- **Heatmap:** Visualized correlations between numerical variables.
- **Pair Plot:** Explored pairwise relationships between distance, fare, tip and total.
- **Violin Plot:** Compared fare distributions by payment method.
