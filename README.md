## 📂 Questions

### String Concatenation

Two strings are concatenated to create a greeting message.

Example:

```python
string1 = "Hello "
name = input("Enter your Name: ")

result = string1 + name
print(result)
```

Output:

```text
Hello Zara
```

Additional text is then added:

```text
Hello Zara, welcome to Python programming
```

The following operations are performed:

### String Methods

The following methods are practiced:

```python
upper()
lower()
capitalize()
count()
replace()
```

Example:

```python
strM = "Python beginner tutorial"

print(strM.upper())
print(strM.lower())
print(strM.capitalize())
print(strM.count('t'))
print(strM.replace("Python", "Machine Learning"))
```

### Tuples

Two tuples are created:

```python
tuple1 = (10, 20, 30)
tuple2 = (40, 50, 60)
```

They are then combined:

```python
t_combine = tuple1 + tuple2
```

Result:

```text
(10, 20, 30, 40, 50, 60)
```

Other operations include:

```python
t_combine * 3
t_combine[2]
t_combine[:3]
t_combine[-3:]
```
